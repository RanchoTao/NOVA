# NOVA roadmap

## v0.1 — completed scaffold
- [x] runnable CLI and localhost reel UI
- [x] curated assumption cards + six inversion operators
- [x] diverse constrained offline baseline and optional model synthesis
- [x] strict schema: IDEA / UNCHECKED and documented falsifier/controls
- [x] preliminary adversarial challenge and inert handoff artifact
- [x] deterministic offline tests and GitHub CI

## v0.2 — credibility before scale
- [ ] independent nearest-neighbor literature retrieval with evidence quotes, date, URLs and claim overlap
- [ ] human-checked research assumption graph, scope/provenance and counterexamples
- [ ] domain-adaptive multi-agent proposer / critic / experiment architect
- [ ] novelty unknown/overlap/confirmed separation; never certify with one LLM
- [ ] persistence, history, deduplication and lineage across sessions
- [ ] real package-level API contracts and CI result verification

## v0.3 — rigorous discovery evaluation
- [ ] equal-token/cost experimental comparison: random slots vs normal brainstorming vs literature-gap baseline vs NOVA
- [ ] blinded expert surprise and scientific-usefulness judgment
- [ ] historical rediscovery with time-censored materials and contamination checks
- [ ] preregistered cheapest falsification on selected ideas; report *all* negative and inconclusive outcomes
- [ ] metrics: valid nontrivial findings per total dollar/hour, diversity and audit failure rate

## v0.4 — actual ecosystem integration
- [ ] validated RanchoControl review request adapter, no task lifecycle bypass
- [ ] RanchoResearch experiment preflight + evidence gate + receipt import
- [ ] progressive compute budgets and per-claim stop criteria
- [ ] manual release gates for publication and expensive work

## Non-goals
Guaranteed Strong Accept; large-scale random combinations as a substitute for scientific judgment; bypassing existing research verification; monetizing subjective 'shock scores'.
